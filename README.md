# 🌄 Explore Araku – Tourism Website

**Explore Araku** is a responsive tourism website designed to help visitors discover the beautiful destinations, waterfalls, caves, viewpoints, coffee plantations, and cultural attractions of Araku Valley, Andhra Pradesh.

The website provides an interactive browsing experience where users can select different destinations and explore their information and images.

## 🚀 Features

- **Interactive Homepage:** Attractive landing page with an Explore Araku banner.
- **Destination Explorer:** Browse multiple tourist attractions in Araku Valley.
- **Dynamic Place Details:** View destination information and images by selecting a place.
- **Responsive Design:** User-friendly interface across desktop, tablet, and mobile devices.
- **Navigation Sidebar:** Easily navigate between different tourist destinations.
- **Tourism Information:** Discover popular attractions and cultural places.
- **Google Maps Integration:** Embedded Google Maps to display tourist destination locations and help visitors explore their geographical locations.

## 🏞️ Destinations Covered

The website features the following destinations:

1. Chaparai Waterfalls
2. Borra Caves
3. Galikonda Viewpoint
4. Madagada
5. Rana Jilleda
6. Tarabu Waterfalls
7. Araku Pinery
8. Duduma Waterfalls
9. Katiki Waterfalls
10. Tribal Museum
11. Coffee Plantation
12. Coffee Museum
13. Chocolate Factory
14. Famous Church
15. Araku Famous School

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and layouts
- **Bootstrap** – Responsive design and UI components
- **JavaScript** – Dynamic interactions and functionality
- **React.js** – Component-based UI development
- **Google Maps Embed API** – Embedding interactive Google Maps to display tourist destinations and their locations.
